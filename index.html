rclone homelab

A private backup tool operated by Frank for his own household.

rclone homelab is the name of a Google OAuth client used by a single private home server. The server runs the open-source program rclone to copy backups of the operator's own documents into the operator's own Google Drive.

What it does

  • Uploads an encrypted backup repository (created with restic) to the operator's Google Drive.
  • Keeps a read-only copy of the operator's own document archive in a dedicated folder of the same Google Drive.

Who can use it

Nobody else. The app is not offered to the public, has no sign-up and is used by exactly one Google account, the operator's own.
